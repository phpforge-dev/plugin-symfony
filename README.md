# PHPForge Symfony plugin

Standalone language worker extracted from PHPForge IDE under the MIT license. Requires IDE 0.2.13 or later. Install from the PHPForge plugin catalog, or install this repository from the Plugins panel. Grant project.read to enable project-aware suggestions. No Node runtime or native executable is required by the IDE. Disable or remove the plugin to stop its language contributions.

Detects symfony/framework-bundle in composer.json and its installed version in composer.lock. Supports PHP route attributes (including class prefixes and automatic names), YAML/XML/PHP routes with RoutingConfigurator collections and `import` prefixes/name prefixes (directories, globs, `@Bundle/`), routes that only exist in the compiled generator (`var/cache/<env>/url_generating_routes.php`, dev first, navigating to the controller method), Twig path/url and template references, container services and parameters, kernel parameters and masked environment references. Doctrine fields (findBy, QueryBuilder, DQL, form `data_class`) come from attribute/annotation mapping and XML mapping (`config/doctrine` plus `type: xml` dirs in `config/packages/doctrine.yaml`), including fields inherited from mapped superclasses, parent entities and traits (resolved through PSR-4) and embeddable paths (`alias.embedded.field`). Navigation opens declaration locations. Project changes invalidate caches. YAML support is intentionally limited to block key/value structures: anchors, flow collections and multiline scalars are not fully resolved. No Symfony process is executed.

## Development

Run `npm ci --ignore-scripts`, `npm test`, and `npm run build`. Commit the generated main.js. CI tests behavior and checks the generated bundle is reproducible. Node and copied host test infrastructure are build/test tooling only; the browser bundle contains only the plugin and required helpers. Synthetic fixtures contain no real project secrets.
